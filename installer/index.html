KIPCast display installer

Install the KIPCast firmware on a Waveshare ESP32-S3 touchscreen, straight from this page. You need Chrome or Edge on a computer, and a USB-C data cable. What is KIPCast?

1. Install

Waveshare ESP32-S3-Touch-LCD-7

7", 800×480. Plug into the USB-C port marked USB, not the one marked UART.

This browser can't install firmware. Use Chrome or Edge on a computer. Open this page over HTTPS to install.

Waveshare ESP32-S3-Touch-LCD-4, Rev4.0

4", 480×480. It has one USB-C port. Earlier revisions aren't supported yet.

This browser can't install firmware. Use Chrome or Edge on a computer. Open this page over HTTPS to install.

Click Connect, choose the screen's port (usually "USB JTAG/serial debug unit"), then Install. When updating a screen that's already set up, leave Erase device unticked to keep its settings.

2. Set up the screen

  1. After installing, the screen shows KIPCast setup and its own WiFi network, called KIPCast- and four characters.
  2. On your phone, join that network. The setup page opens by itself; if it doesn't, browse to http://192.168.4.1.
  3. Choose the boat's WiFi, enter its password and give the screen a display id, for example helm. Leave Signal K server blank and the screen finds it on the network by itself.
  4. Save. The screen restarts, joins the WiFi and connects to the KIPCast plugin in Signal K.

To change the settings later, touch and hold the screen for two seconds while it shows Starting or any other status message.

If it doesn't work

  1. No port to choose: try another cable, as some only carry power. On the 7", check you're using the port marked USB. If it still doesn't appear, hold the BOOT button while plugging the cable in.
  2. The 7" screen stays blank after installing: unplug it and plug it back in. One of its display lines shares a pin that can leave it in download mode after a reset.
  3. The screen can't find Signal K: check the KIPCast plugin is installed and enabled in Signal K. Or open setup and enter the Pi's IP address as the Signal K server.
