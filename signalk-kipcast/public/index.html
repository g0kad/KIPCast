Setting up a new screen size

  1. In Security → Users, create a Signal K user for the size, for example kip480.
  2. On a computer, open KIP in an ordinary browser, log in as that user and build the dashboards there. It's much easier than editing on the touchscreen.
  3. Click Open for the display above and log its KIP in as the same user. The dashboards load from Signal K.
  4. With the screen in view, resize and move widgets in the viewer. It's drawn at the screen's exact size and changes show on the screen straight away.

Add a display

Use the same id as on the screen's setup page. You only need to add a display here to set up its dashboards before the screen has connected; screens add themselves.
